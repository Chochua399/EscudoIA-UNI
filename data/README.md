# Fuente de datos

- Dataset oficial: SpaPhish v5 (Mendeley Data).
- DOI: https://doi.org/10.17632/hz2d6gz7pc.5
- Licencia: Creative Commons Attribution 4.0 (CC BY 4.0).
- CSV con delimitador de punto y coma, `subject`, `body` y `Label` (0=legítimo, 1=phishing).
- El CSV no se distribuye dentro de este ZIP. Se descarga de Mendeley por el usuario y se coloca en `data/raw`.
- `data/raw` no se modifica. Los derivados se guardan en `data/processed`.
- No insertar mensajes privados de personas reales en el repositorio sin permisos y anonimización.
